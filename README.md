# Сложно сосредоточиться

Учебный проект Яндекс Практикума — адаптивная страница о причинах потери концентрации и способах вернуть внимание.

Проект выполнен по макету Figma с использованием HTML и CSS. Основная задача — перенести композицию макета на разные размеры экрана и настроить светлую, тёмную и автоматическую цветовые схемы.

## О проекте

Страница включает:

- шапку с заголовком и переключателем тем;
- раздел о причинах трудностей с концентрацией;
- раздел о факторах, снижающих внимание;
- пять советов для улучшения концентрации;
- галерею иллюстраций;
- подвал с декоративным заголовком.

Вёрстка выполнена по подходу Mobile First. Основные размеры макета — 375, 768 и 1024 px. Максимальная ширина содержимого — 1440 px.

## Что реализовано

1. Семантическая разметка с header, main, section, article и footer.
2. Адаптивная раскладка основных разделов и галереи на CSS Grid.
3. Изменяемый размер крупных заголовков через clamp().
4. Цветовые схемы через CSS-переменные и классы theme-light, theme-dark, theme-auto.
5. Автоматический выбор темы по prefers-color-scheme.
6. Декоративные уголки и точка REC через псевдоэлементы.
7. Состояния наведения и клавиатурного фокуса у ссылок и кнопок.
8. Альтернативные описания и отложенная загрузка изображений галереи.

Выбранную тему сохраняет предоставленный JavaScript в localStorage. В светлой теме декоративная надпись REC скрыта.

| Технология | Назначение |
| --- | --- |
| HTML5 | Семантическая структура и изображения |
| CSS3 | Оформление страницы |

## Организация файлов

| Файл или папка | Содержимое |
| --- | --- |
| index.html | Структура и текст страницы |
| styles/globals.css | Базовые стили и сброс отступов |
| styles/variables.css | Основные CSS-переменные |
| styles/style.css | Оформление блоков и адаптивная раскладка |
| styles/dark.css | Принудительная тёмная тема |
| styles/light.css | Светлая тема и системные настройки |
| scripts/script.js | Переключение тем |
| fonts/ | Локальные шрифты и их подключение |
| images/ | Фоны, иллюстрации и фавиконки |
| .github/workflows/tests.yml | Проверки GitHub Actions |

## Запуск

Откройте папку проекта в VS Code и запустите index.html через Live Server. Установка зависимостей и сборка не требуются.
